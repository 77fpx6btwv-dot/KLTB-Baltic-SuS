# KLTB Baltic SuS (GitHub Pages)

1. Auf github.com neues Repository anlegen (z. B. `kltb-sus`), Sichtbarkeit: Public (kostenloses Pages).
2. „Add file → Upload files“: **alle Dateien dieses Ordners** hochladen (index.html, manifest.webmanifest, .nojekyll, Ordner icons/) → Commit.
3. Settings → Pages → Source: „Deploy from a branch“ → Branch `main`, Ordner `/ (root)` → Save.
4. Nach ca. 1 Min. erreichbar unter `https://<benutzername>.github.io/kltb-sus/`.
5. Auf dem Handy in Safari/Chrome öffnen → Teilen → „Zum Home-Bildschirm“.

Update: index.html im Repo ersetzen (Upload mit gleichem Namen). Daten der SuS bleiben im Browser erhalten.
Hinweis: Alte Daten aus Documents vorher mit „💾 Meine Daten sichern“ exportieren und im Browser per „📂 Daten laden“ importieren (localStorage gilt pro Adresse).
